# EleNetflix

La maratona Marvel verso Avengers: Doomsday (16 dicembre 2026): 40 titoli più il gran finale.

Sito statico in una sola pagina (`index.html`). Voti e titoli visti restano nel browser di ogni telefono; si spostano con il backup JSON.

Locandine: [TMDB](https://www.themoviedb.org). Questo prodotto usa l'API di TMDB ma non è approvato né certificato da TMDB. Nessuna chiave API è contenuta nel codice.

Progetto personale, non affiliato a Netflix, Marvel, Disney o Sony.
